# Prompt Kit Humas Sekolah Muhammadiyah

> Suite Produktivitas & Generator Prompt AI Berbasis Formula PANDU untuk Tim Kehumasan Sekolah Muhammadiyah.

🌐 **Live Web App:** [https://prompt-kit-humas-sekolah-muhammadiyah.netlify.app](https://prompt-kit-humas-sekolah-muhammadiyah.netlify.app)

Aplikasi web modern yang dirancang untuk mempercepat dan meningkatkan kualitas produksi konten publikasi, komunikasi orang tua, rilis berita jurnalistik, dan promosi PPDB sekolah Muhammadiyah secara etis dengan prinsip **Human-in-the-Loop** (AI sebagai penyusun draf cepat, manusia sebagai penentu dan verifikator akhir).

---

## 🌟 Fitur Utama

1. **⚡ Generator Prompt (Formula PANDU)**
   - Kerangka 5 langkah terstruktur: **P**eran, **A**udiens, **N**iat, **D**etail fakta, dan **U**ntukan format.
   - Pilihan platform: Instagram Feed/Carousel, TikTok & Reels (Video News TV 1.30–2 Menit Berbasis 5W+1H), dan WhatsApp Broadcast.
   - Nilai unggulan: Tahfidz Al-Qur'an, Sains & Literasi Digital, Bakat & Minat, Wirausaha Cilik, Adab & Karakter.
   - Opsi kearifan lokal: **Sentuhan Minangkabau** (*Adat Basandi Syarak, Syarak Basandi Kitabullah* / ABS-SBK & pepatah-petitih).
   - Kalimat Perisai & Rambu Anti-Halusinasi otomatis.

2. **📚 Library Prompt Siap Pakai**
   - **📰 Berita Rilis (Kaidah Kompas.com & Dewan Pers)**: Dilengkapi fitur **Edit / Tempel Draf Kasar** langsung di aplikasi untuk otomatis disatukan dengan seluruh kaidah jurnalistik (UU Pers No. 40/1999, KEJ, piramida terbalik, 5W+1H, SEO Google Discover).
   - Template Instagram Carousel 7 Slide, Caption Apresiasi Prestasi Siswa, Profil Guru Storytelling, Broadcast PPDB Ramah, Video News Naskah Reels/TikTok 1.30 Menit (Gaya News TV 5W+1H), Brief Tim Dokumentasi, Pernyataan Klarifikasi Isu (Manajemen Krisis), dan Evaluasi Bio/Feed.
   - Bilah pencarian instan dan filter kategori.

3. **📅 Kalender & Timeline Editorial Bulanan**
   - Matriks kalender dinamis (Senin s/d Minggu) dengan ritme marketing funnel (*Awareness*, *Consideration*, *Engagement*, *Conversion*).
   - Pilihan frekuensi posting: 7 hari (harian), 5 hari kerja, atau 3 hari unggulan.
   - **Inline Edit**: Klik edit pada tanggal mana pun dan ketik rencana manual (tersimpan otomatis di `localStorage` peramban).
   - Salin seluruh jadwal dan siap cetak (*print / save to PDF ready*).

4. **🧭 Edukasi Formula PANDU & 4 Pilar Orang Tua**
   - Panduan mendalam tentang kekhawatiran utama orang tua saat memilih sekolah: Rasa Aman, Mutu Belajar, Karakter & Ibadah, serta Nilai Investasi Biaya.
   - Prinsip mendasar: *"Bintang kontennya adalah siswa, bukan seremonial orang dewasa"*.

5. **🎨 Desain Elegan Apple Human Interface Guidelines (HIG)**
   - Gradasi warna mewah **Emerald Midnight & Brushed Imperial Gold**.
   - Mode ganda: **Dark Mode & Light Mode** dengan peralihan mulus.
   - Efek kaca transparan (*Frosted Glass / Vibrancy*).
   - **Apple Floating Dock** untuk navigasi ramah jempol pada perangkat seluler.
   - Notifikasi salin ala **Dynamic Island**.

## 💻 Cara Menjalankan

Aplikasi ini 100% mandiri (*zero-dependency / offline-ready*) menggunakan HTML5, CSS3, dan Vanilla JavaScript.

### Opsi 1: Langsung Buka di Browser
Klik dua kali file `index.html` pada File Manager / Finder Anda, atau buka via peramban web (Safari, Chrome, Firefox, Edge).

### Opsi 2: Jalankan via Local Server (Python)
```bash
# Masuk ke direktori
cd humas-muhammadiyah

# Jalankan server lokal
python3 -m http.server 8080
```
Buka browser dan akses `http://localhost:8080`.
